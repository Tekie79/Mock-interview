# Navigation and layout

The workspace uses a native selection sidebar for Live Interview, Profiles, History, Practice and Settings. The sidebar can collapse into a persistent icon rail. The session control bar remains below every destination. Moving between destinations leaves the interview lifecycle in the app-owned model.

## Live Interview

The top header identifies the session, profile and elapsed time. Audio configuration opens from the control bar or idle preparation. Focus and Chat share answer formats, history, and generation actions. Focus provides previous, next and pin. Chat shows chronological immutable question identities with replaceable answer revisions. Moving away from the latest turns suspends automatic following. Jump to Latest resumes it and reports the number of unseen new answers. Fit Latest aligns the start of the newest answer when following. Answers taller than the viewport remain scrollable at the chosen reading size.

The optional inspector shows the attributed transcript or learned context. Transcript preserves provisional and final text and compatible speaker assignment. Learned Context links items to their source, capture epoch and related turns, with controls to correct, exclude, restore or clear context. Approved profile evidence has a separate presentation.

## Compact

Compact opens a resizable companion window with one shared session, presentation preference and answer history. Each Chat scroll position is local to its window. Compact contains session controls, an Always on Top preference and an Expand Workspace action. The workspace has a 760 × 530 pt minimum and Compact has a 300 × 210 pt minimum.

## Library and preferences

Profiles and History use a list and detail layout. Profiles expose Overview, Skills, Experience, Projects, Documents and Answer Preferences. History offers search, evaluation filtering, transcript and suggested answer review, notes, export and deletion. Practice follows prompt, actual response and coaching. Settings has seven categories with alternative providers and presets under AI and Models.
