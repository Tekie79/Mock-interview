# Provider capabilities and authority

| Provider | Transcription | Classification / text | Authentication and billing |
|---|---|---|---|
| Apple Speech | Common PCM from any route, local discovery, explicit strict or network-permitted mode, partials, per-segment rollover, vocabulary hints | Unavailable | macOS Speech Recognition permission |
| OpenAI API | GA Realtime transcription WebSocket, 24 kHz PCM, acknowledged configuration, manual commit, ordered provider finals. Vocabulary prompt only on compatible models | Responses structured decisions, SSE text, optional independent embeddings | Keychain API key; separately billed API |
| ElevenLabs | Scribe v3 Live and v2 Realtime, 24 kHz PCM, replacement partials, committed timestamps, locale/detection and keyterms. Manual/VAD, with turn prediction on v3 only | Unavailable | Keychain API key; separately billed usage which can include silence |
| Deepgram | Nova streaming, timestamp metadata, configurable endpointing, scoped speaker labels, KeepAlive and CloseStream | Unavailable | Keychain API key; separately billed API |
| Anthropic Claude | Unavailable | Messages structured output and streaming text on supported models | Keychain API key; separately billed API |
| ChatGPT subscription | Unavailable under the documented plan preview | Browser linking, account-specific model discovery and streamed Responses are implemented for eligible distributions. Each text service requires a successful model check | Separate OAuth token and Keychain domain. Live activation requires confirmed eligibility |

Transcription, classifier, answer and embeddings selections are independent. Connection tests are per service and can send synthetic requests. Provider model lists are documented possibilities, with account availability validated on connection. Diagnostic messages expose typed states and counters and omit response bodies, credentials and dialogue.

## Apple Speech

On macOS 26 and later, strict recognition selects the on-device SpeechAnalyzer path when compatible assets are already installed and no custom vocabulary is requested. It negotiates the analyzer's PCM format, handles volatile and final ranges, and drains after input ends. Earlier systems, network-permitted mode and custom vocabulary use the classic `SFSpeechAudioBufferRecognitionRequest` path. It discovers installed recognizer capabilities for the selected locale, applies `requiresOnDeviceRecognition` on every strict request and never automatically switches to network recognition. It uses bounded overlapping tasks for completed segments and publishes finals in request order. Speech permission, actual recognizer availability, language accuracy and resource behavior need a physical Mac. [Apple Speech](https://developer.apple.com/documentation/speech)

## ElevenLabs

The native WebSocket checks the `session_started` model and PCM format before capture. It sends batched 24 kHz mono PCM and tracks submitted voice, commit requests and transcript companions independently. Its voiced-audio tracking uses the same local sensitivity as the transcription channel. A timestamped final can clear only attributable earlier audio. A missing, empty, duplicate or unpositioned result cannot acknowledge newer pending speech. An unresolved drain reports incomplete transcription. Scribe v3 Live turn probability contributes completion evidence alongside the source role and question checks. Submitted PCM is a local usage estimate. Provider billing can include silence. The adapter requests `enable_logging=false`, and ElevenLabs may still log sessions when zero retention is unavailable on the account. Deepgram supplies the live speaker labels used for explicit role assignment. [Realtime wire](https://elevenlabs.io/docs/api-reference/speech-to-text/v-1-speech-to-text-realtime) · [Commit strategies](https://elevenlabs.io/docs/eleven-api/guides/how-to/speech-to-text/realtime/transcripts-and-commit-strategies)

The adapter subtracts each timestamped final from the pending voiced intervals. It tolerates a remainder of at most 20 ms per edge when the final overlaps at least 20 ms or half the pending interval, whichever is smaller. Each explicit commit needs a corresponding timestamped result and resolution of the voice inside its sample window. Later results can leave earlier commits pending. Plain commit companions retain order when available. An older timestamp-only result can still resolve a pending interval. These tolerances account for word boundaries in development and need live-provider qualification.

## OpenAI and Deepgram transcription

OpenAI requires an effective transcription-session acknowledgment for the selected model, 24 kHz PCM and client-controlled commits. `gpt-live-transcribe` uses the documented language and keyword arrays, `gpt-transcribe` also exposes detected languages after commit, and legacy prompt-capable models retain their distinct fields. The adapter consumes documented per-item completion usage when present. Deepgram uses Nova's live WebSocket contract with raw PCM, model-specific vocabulary and multilingual options, `KeepAlive`, and `CloseStream` followed by final events and summary metadata. Deepgram usage records redact user-supplied vocabulary. The reported locally submitted PCM count is separate from provider-reported usage. [OpenAI Realtime transcription](https://developers.openai.com/api/docs/guides/realtime-transcription) · [Realtime client events](https://developers.openai.com/api/reference/resources/realtime/client-events) · [Deepgram streaming](https://developers.deepgram.com/reference/speech-to-text/listen-streaming) · [Deepgram finalization](https://developers.deepgram.com/docs/finalize)

## Anthropic

Classification uses the Messages `output_config.format` JSON schema and rejects interrupted or refused output. Answer generation reads Messages SSE until a supported stop reason. The adapter handles cumulative output usage and includes cache-read and cache-creation counts in total input tokens. Token counts are usage units and do not imply a price. Model-access or schema incompatibilities surface in the selected service's connection test. [Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs) · [Streaming Messages](https://platform.claude.com/docs/en/build-with-claude/streaming)

## ChatGPT plan authorization

The app implements system-browser linking, a `127.0.0.1` callback, PKCE, signed ID validation, account switching, per-registration Keychain records, refresh rotation and revocation. The subscription provider uses the signed-in account's catalog and the public streamed Responses endpoint with OAuth plan credentials. Identity-only accounts can reauthorize for plan usage. The native account panel includes the official usage-management link. The deterministic suite uses synthetic grants and mocked transports, plus a native HTTP loopback fixture. [Registration and sign-in](https://developers.openai.com/siwc/token-sharing-open-source/sign-in) · [Accounts and sessions](https://developers.openai.com/siwc/token-sharing-open-source/profiles-and-sessions) · [Models and inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference) · [Preview limits](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)

**Owner activation.** The repository currently has no declared distribution license or documented OpenAI approval. For the open-source and locally hosted route, the owner must select and publish an open-source license if choosing that distribution, and document that the exact distribution qualifies under OpenAI's preview terms. If eligibility is unclear, obtain confirmation from OpenAI. For a paid or remotely hosted offering, submit OpenAI's interest form and obtain approval and the supported integration details for this app. Once documented, enable `ChatGPTPlanEligibility.desktopAvailable` in a reviewed change for the confirmed flow and validate linking, reauthorization, refresh, sign-out and both model capability checks with an authorized account. The current build keeps the gate closed.
