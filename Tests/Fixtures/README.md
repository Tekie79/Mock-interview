# Synthetic development fixtures

`question-turns.json` is a small hand-authored test corpus, not an accuracy benchmark. Each entry has `id`, `role` (`interviewer`, `candidate`, `unknown`), `text`, `isComplete`, `expected` (`accept`, `ignore`, `wait`, `uncertain`), and `note`. `logicalTurnID` and `contextTurnIDs` are optional; the duplicate example is expected to be ignored on its second appearance within the same session. Cases are ordered; treat each independent case separately except explicitly linked repeats/duplicates. The fixture is input for M03/M04, not yet consumed by the initial role-only tests. Add structured provider event and timing fixtures as the pipeline is implemented. Use synthetic content and a separate held-out qualification set; no user recordings or résumés.
